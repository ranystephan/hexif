# Code of Conduct

HEXIF is a scientific open-source project. We want it to be a welcoming,
professional environment for researchers, students, and engineers of every
background.

## Expected behavior

- Be respectful and constructive in all interactions.
- Assume good intent; ask questions before assuming malice.
- Give credit where due; cite prior work.
- Prefer technical arguments over personal ones.
- Help newcomers get oriented.

## Unacceptable behavior

- Personal attacks, insults, or sustained disruption of discussion.
- Harassment of any kind, in public or private project spaces.
- Publishing others' private information without consent.
- Plagiarism or misrepresentation of authorship.

## Scope

This code applies to all project spaces: the GitHub repository, issues, pull
requests, discussions, and any official communication channels.

## Reporting

If you experience or witness behavior that violates this code, please contact
the maintainer directly at **ranyc@stanford.edu**. Reports will be handled
confidentially.

Maintainers reserve the right to remove comments, commits, issues, or
contributors that violate this code.
